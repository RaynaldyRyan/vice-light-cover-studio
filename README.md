Vice Light Cover Studio — an offline web app that turns your photos and a caption into GTA 6-style multi-panel cover art (Vice City sunset/neon grade) and exports it as a PNG in 1080×1080, 1080×1350 and 1920×1080. Six layouts, five gradient-map grades with posterization and ink outlines, gradient display lettering with a neon script subtitle, per-panel crop and position, undo/redo — all offline, photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
